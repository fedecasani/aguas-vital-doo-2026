# Aguas Vital - Diseño Orientado a Objetos

Trabajo práctico integrador de Diseño Orientado a Objetos.

## Base inicial

El proyecto parte de `ejemploCompletoFX`, provisto por la cátedra, y se
desarrollará de forma incremental para implementar los casos de uso principales
del sistema Aguas Vital SA.

## Tecnologías

- Java
- JavaFX y FXML
- Maven
- SQLite
- DAO, DTO y patrones de diseño

## Ejecución

```bash
mvn clean javafx:run
```
